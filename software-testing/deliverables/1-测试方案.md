## 1 概述

### 1.1 编写目的
确认被测系统模块划分、测试范围、测试人员、外部资源与风险控制方式，作为后续用例编写、接口执行、缺陷登记和测试总结的依据。

### 1.2 阅读对象
最终用户、项目负责人、评审人员、测试人员、开发人员。

### 1.3 系统背景
RhizoDelta 是图谱化非线性讨论系统（B/S，Spring Boot + Neo4j + React/Vite），通过图数据库组织讨论节点与关联，通过 Redis/RabbitMQ/SSE 支撑令牌状态、异步处理和实时推送。本次测试重点验证认证授权、用户资料与社交、图谱查询等核心 REST 行为，详见 [../docs/project-understanding.md](../docs/project-understanding.md)。
