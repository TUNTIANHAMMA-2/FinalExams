# 演示流程脚本（答辩现场）

> 目标：3–5 分钟内展示"被测系统能跑 + 测试有依据 + 缺陷有产出"。

## 0. 准备

- 确认后端运行：`http://localhost:8090`（如未运行，先在 RhizoDelta 仓库按其 README 启动）。
- 打开 Postman，导入接口用例集（见 deliverables/4）。

## 1. 系统可用性（30s）

- 浏览器打开前端首页，展示图谱讨论界面，登录一个测试账号。

## 2. 功能用例演示（1–2min）

- 取 1–2 条代表性用例：如"登录-密码错误 → 提示失败"、"发帖 → 节点出现在图谱"。
- 对照 deliverables/2 的预期输出说明结果一致 / 不一致。

## 3. 接口测试演示（1–2min）

- Postman 跑认证流：register → login（拿 token）→ 带 token 调 `/api/auth/me`。
- 演示一个反例：不带 token 调受保护接口 → 401，展示 Tests 断言通过。
- 用 Collection Runner 跑一组，展示通过率与导出的报告。

## 4. 缺陷展示（30s）

- 打开 deliverables/3，挑 1 个真实缺陷讲清楚：复现步骤、严重程度、定位。

## 5. 收尾（30s）

- 给出测试结论与改进建议（呼应总结报告第 8 节）。
