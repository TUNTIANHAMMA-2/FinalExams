# Python 数据收集与分析期末考查答辩稿

## 1. 开场

老师好，我本次完成的项目是“药品销售数据处理与分析”。项目使用 Python 的 Pandas、NumPy、Matplotlib 和 Seaborn，对给定的药品销售 Excel 数据完成数据加载、清洗、异常处理、统计分析和可视化。

## 2. 数据与目标

原始数据共有 6578 行、8 列，字段包括购药时间、社保卡号、商品编码、商品名称、销售数量、应收金额、实收金额和星期。根据评分标准，我需要完成四类任务：第一是读取数据并查看基本信息；第二是修正列名并处理重复值、缺失值和异常值；第三是完成月度、星期和药品维度的统计分析；第四是用图表展示分析结果。

## 3. 数据处理思路

我先用 `pandas.read_excel()` 读取 Excel，并检查字段是否完整。之后把 `购药时间` 改成 `销售时间`，再把销售时间统一转换为 DateTime 类型，把销售数量转换为整型，把金额字段转换为数值类型。

在清洗阶段，我把异常分成两类：确定错误和统计异常。无效日期、关键字段缺失、销售数量或金额小于等于 0 的记录属于确定错误，直接剔除。本次共剔除 68 行，清洗后保留 6510 行。对于 IQR 检测出来的大额或大数量记录，我没有直接删除，而是输出到异常表中保留复核，因为药品销售里可能存在真实的批量购买。

## 4. 分析结果

清洗后的数据覆盖 2022 年 1 月 1 日到 2022 年 7 月 19 日。月均实收金额为 43434.98 元，其中 2022 年 1 月实收金额最高，为 49461.19 元。

按星期统计，星期五的订单数、销售数量和实收金额最高，实收金额为 51284.66 元，说明星期五销售表现最好。

按商品名称统计销售数量，排名第一的是苯磺酸氨氯地平片(安内真)，销售数量为 1781；第二是开博通，销售数量为 1440，但开博通的实收金额更高，说明单价差异会影响金额表现。

## 5. 可视化展示

我生成了三张图：第一张是销售时间与每日实收金额关系图，用来观察不同日期的销售波动；第二张是星期分组统计图，把销售数量、应收金额和实收金额放在同一张图中对比；第三张是销售数量前十药品图，用横向柱状图展示 Top 10 药品。

## 6. 总结

这个项目完整覆盖了数据加载、数据概览、列名修正、重复值处理、缺失值处理、异常值处理、数据排序、月均金额计算和可视化分析。我的代码把清洗、统计和绘图拆成独立函数，并添加了可读注释，方便检查和维护。最终输出包括清洗后的数据、统计表、异常记录、图表、报告和答辩文档。
