# 项目理解速览

## 1. 一句话介绍

本项目是《Python数据收集与分析》期末考查作业，围绕药品销售 Excel 数据完成清洗、统计分析和可视化，最终形成可运行代码、分析结果、报告和答辩材料。

## 2. 题目要求

根据评分标准，需要完成：

- 数据加载。
- 查看数据基本信息。
- 将 `购药时间` 修正为 `销售时间`。
- 处理重复值、缺失值和异常值。
- 将销售数量统一为整型。
- 将销售时间统一为 DateTime 类型。
- 按销售时间排序并重置索引。
- 计算月均销售金额。
- 绘制销售时间与实收金额关系图。
- 按星期统计销售数量、应收金额和实收金额。
- 统计销售数量前十位药品并绘图。
- 完成 3 分钟项目汇报。

## 3. 数据内容

原始 Excel 包含 6578 行、8 列：

| 字段 | 说明 |
| --- | --- |
| 购药时间 | 原始日期字段 |
| 社保卡号 | 顾客标识 |
| 商品编码 | 药品编码 |
| 商品名称 | 药品名称 |
| 销售数量 | 本次销售数量 |
| 应收金额 | 理论应收金额 |
| 实收金额 | 实际收款金额 |
| 星期 | 原始星期字段 |

## 4. 项目定位

本项目不是机器学习建模项目，而是数据分析流程训练。重点是：

- 使用 Pandas 处理真实 Excel 数据。
- 用清晰规则说明数据清洗决策。
- 用统计表和图表支撑结论。
- 让报告内容和代码运行结果一致。
