# 宿舍报修管理系统辅助文档

本目录用于补充《软件工程导论》正式报告，帮助快速理解选题、系统设计、答辩演示顺序和常见追问。

- `../软件工程导论期末大作业试题.docx`
- `../《软件工程导论》期末考查报告模板.doc`
- `../宿舍报修管理系统软件工程导论期末考查报告.doc`
- `../宿舍报修管理系统软件工程导论期末考查报告.pdf`

辅助文档建议阅读顺序：

1. [项目理解速览](./project-understanding.md)：先理解选题背景、业务边界和报告主线。
2. [系统设计说明](./system-design.md)：按需求分析、总体设计、详细设计和测试展开。
3. [演示流程脚本](./demo-flow.md)：答辩现场按报告章节展示设计成果。
4. [答辩提纲](./defense-outline.md)：用于制作 PPT 或组织口头汇报。
5. [答辩常见问答](./defense-qa.md)：提前准备老师可能追问的问题。

说明：本作业是软件工程方法报告型作业，重点在于说明从问题定义、需求分析、总体设计、详细设计到测试设计的完整过程。
