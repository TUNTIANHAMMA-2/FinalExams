## 结构说明

- `generated/` 保存报告生成过程中的 Markdown、MHT、兼容 docx 和检查说明，属于中间产物。
- `generate_dorm_repair_report.py` 是报告生成脚本，正式提交时通常不需要提交脚本。
- 最终提交建议优先使用 `.doc` 和 `.pdf` 报告，并带上 `答辩.md` 作为答辩准备材料。
