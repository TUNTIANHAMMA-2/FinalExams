本目录用于补充正式课程设计报告，帮助快速理解 RhizoDelta 后端设计、准备现场演示和组织答辩表达。

辅助文档建议阅读顺序：

1. [项目理解速览](./project-understanding.md)：先理解项目背景、业务目标和课程适配关系。
2. [系统设计说明](./system-design.md)：按后端架构、认证、数据、消息、实时事件和部署展开。
3. [演示流程脚本](./demo-flow.md)：答辩现场按步骤展示系统和报告。
4. [答辩提纲](./defense-outline.md)：用于制作 PPT 或组织口头汇报。
5. [答辩常见问答](./defense-qa.md)：提前准备老师可能追问的问题。

说明：课程考查方案偏向 Spring Boot + MyBatis-Plus 的单表 CRUD 系统，RhizoDelta 实际使用 Spring Boot + Spring Data Neo4j + RabbitMQ + Redis + React。答辩时应主动说明技术差异，并强调课程知识点在真实工程中的对应实现。
