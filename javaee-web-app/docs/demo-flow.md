# 演示流程脚本

本文档用于答辩现场演示。建议演示时间控制在 5 到 7 分钟，重点展示企业级后端能力和课程知识点对应关系。

## 1. 演示前准备

准备材料：

- 正式报告：`../JavaEE企业级Web应用开发实战期末课程设计报告.docx`
- 快速答辩稿：`../答辩.md`
- 本目录辅助文档
- 如果需要展示真实源码，可准备 RhizoDelta 后端工程目录。

建议提前打开：

1. 报告技术选型页。
2. 系统总体架构。
3. 数据库设计。
4. 认证授权章节。
5. RabbitMQ 和 SSE 相关章节。
6. 文件上传、异常处理、部署章节。

## 2. 开场介绍

建议 30 秒说明：

“本课程设计基于 RhizoDelta 图谱化非线性讨论系统。它在课程常见的信息管理能力基础上，加入认证授权、图数据库、消息队列、缓存、文件上传、实时推送和监控部署等企业级 Web 能力。报告重点说明课程知识点如何在真实工程中对应落地。”

## 3. 演示步骤

### 步骤一：说明课程适配关系

讲解点：

- 课程方案偏向 Spring Boot + MyBatis-Plus 管理系统。
- 本项目使用 Spring Boot + Neo4j，但仍覆盖持久化、分页、事务和逻辑删除。
- 技术差异来自业务对象是图结构，查询重点从单表维护扩展到节点关系、谱系和溯源。

### 步骤二：展示总体架构

讲解 Controller、Service、Repository、Infrastructure 的分层。

可说的话：

“控制器只处理请求入口，核心业务放在 Service 层，图数据访问由 Repository 和 Neo4jClient 负责，消息、认证、SSE、文件存储放在基础设施层。”

### 步骤三：展示认证授权

讲解点：

- Spring Security 过滤器链。
- JWT token。
- BCrypt 密码加密。
- Redis 保存 refresh token 和黑名单。

### 步骤四：展示图数据库设计

讲解点：

- `Human_Post`、`AI_Consensus`、`Result`、`Topic` 等节点。
- `BRANCHED_FROM`、`MERGED_INTO`、`SYNTHESIZED_FROM` 等关系。
- 图数据库适合表达谱系、溯源和观点演化。

### 步骤五：展示发帖异步链路

讲解点：

- 前端发帖后后端返回排队状态。
- RabbitMQ 接收消息。
- 消费者异步处理。
- SSE 推送节点和边的增量事件。

可说的话：

“这里体现了企业级 Web 中常见的异步解耦思想。高成本任务不阻塞用户请求，而是通过消息队列和事件推送完成。”

### 步骤六：展示文件上传和异常处理

讲解点：

- 头像上传使用 MultipartFile。
- 统一异常处理保证错误响应格式一致。
- 日志和监控便于定位运行问题。

### 步骤七：总结课程知识点

用表格说明课程要求与项目实现：

- Spring Boot 工程。
- RESTful API。
- 数据持久化。
- 登录认证。
- 缓存和消息队列。
- 文件上传。
- 测试和部署。

## 4. 收尾总结

建议 30 秒总结：

“这个项目用图谱讨论这一真实业务场景覆盖了 JavaEE 企业级 Web 应用开发的核心能力。答辩重点是说明我理解这些技术为什么使用、如何分层、怎样保证链路可靠。”

## 5. 备用演示方案

如果现场无法运行真实后端：

1. 使用正式报告中的架构图和模块说明。
2. 打开答辩稿说明技术选型。
3. 重点讲认证、图数据库、RabbitMQ 和 SSE 四条链路。
4. 用报告中的接口和数据模型说明实现依据。
