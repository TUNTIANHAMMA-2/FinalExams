# 物流管理系统课程设计报告

## 一、项目概述

本项目为 JavaEE 企业级 Web 应用开发实战期末课程设计，系统主题为物流管理系统。系统面向物流企业的日常运单管理场景，提供客户、司机、车辆基础资料展示，以及物流运单的查询、新增、修改、删除等功能。

项目采用 Spring Boot 作为基础框架，使用 Spring MVC 完成 Web 层开发，使用 Thymeleaf 渲染后台管理页面，使用 MyBatis-Plus 完成 MySQL 数据库的 CRUD 操作。系统结构简单清晰，便于课程作业提交、运行截图和答辩说明。

## 二、需求分析

### 2.1 功能需求

1. 工作台统计：展示客户数量、司机数量、车辆数量、运单数量和运单状态分布。
2. 基础资料管理：展示客户、司机、车辆测试数据，为运单创建提供基础信息。
3. 运单管理：支持按关键字和状态查询运单，支持新增、编辑、删除运单。
4. RESTful 接口：提供运单的 GET、POST、PUT、DELETE 接口。
5. 统一响应：接口返回结果包含 `code`、`message`、`data` 字段。
6. 数据持久化：使用 MyBatis-Plus 操作 MySQL 数据库。

### 2.2 非功能需求

1. 代码结构清晰，按照 controller、service、mapper、entity 分层。
2. 配置文件支持 dev/prod 多环境切换。
3. 表单参数使用 Bean Validation 做基础校验。
4. 运单新增、修改、删除使用事务控制。
5. 提供数据库建表脚本和测试数据，便于老师本地运行检查。

## 三、系统技术架构

系统采用单体 MVC 架构，浏览器通过 Thymeleaf 页面访问业务功能，也可以通过 REST API 访问运单资源。

```text
浏览器/接口测试工具
        ↓
Controller 层：页面请求、REST 请求、参数接收
        ↓
Service 层：业务逻辑、事务控制、状态校验
        ↓
Mapper 层：MyBatis-Plus CRUD 和关联查询
        ↓
MySQL 数据库：客户、司机、车辆、运单表
```

## 四、数据库设计

数据库名为 `logistics_db`，包含四张核心业务表。

| 表名 | 说明 |
| --- | --- |
| `lm_customer` | 客户信息表，保存客户名称、联系人、电话、地址 |
| `lm_driver` | 司机信息表，保存司机姓名、电话、驾驶证号、状态 |
| `lm_vehicle` | 车辆信息表，保存车牌号、车型、载重、状态 |
| `lm_shipment` | 运单表，保存客户、司机、车辆、线路、货物、运费、状态 |

运单表通过 `customer_id`、`driver_id`、`vehicle_id` 与客户、司机、车辆表建立关联，便于查询运单时展示完整物流信息。

## 五、核心代码说明

### 5.1 统一响应封装

`ApiResponse<T>` 用于封装 REST 接口返回结果，包含 `code`、`message`、`data` 三个字段。接口成功时返回 `ApiResponse.ok(data)`，失败时返回 `ApiResponse.fail(code, message)`。

### 5.2 RESTful Controller

`ShipmentRestController` 提供运单接口：

- `GET /api/shipments`：查询运单列表，使用 `@RequestParam` 接收查询参数。
- `GET /api/shipments/{id}`：查询运单详情，使用 `@PathVariable` 接收路径参数。
- `POST /api/shipments`：新增运单，使用 `@RequestBody` 接收 JSON 请求体。
- `PUT /api/shipments/{id}`：修改运单。
- `DELETE /api/shipments/{id}`：删除运单。

### 5.3 Service 事务控制

`ShipmentServiceImpl` 在新增、修改、删除方法上使用 `@Transactional(rollbackFor = Exception.class)`。当业务处理出现异常时，数据库操作会自动回滚，保证运单数据一致性。

### 5.4 MyBatis-Plus 持久层

客户、司机、车辆和运单 Mapper 继承 MyBatis-Plus 的 `BaseMapper`，直接获得基础 CRUD 能力。运单列表额外使用 `selectShipmentViews` 关联查询客户名称、司机姓名和车牌号，便于页面展示。
