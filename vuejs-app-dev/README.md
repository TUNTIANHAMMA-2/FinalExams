## 结构说明

- `generated/` 保存生成报告时输出的 HTML 等中间文件。
- `images/` 保存报告图示和界面/代码截图。
- `.venv-docs/` 是本地文档生成环境，不作为正式提交材料。
- 由于课程名和真实技术栈存在差异，答辩时应主动说明：报告使用 RhizoDelta 真实前端作为课程设计载体，实际技术栈为 React、TypeScript、Vite、Zustand、React Router、React Flow 和 SSE。
