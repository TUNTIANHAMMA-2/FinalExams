# 项目理解速览

## 1. 一句话介绍

RhizoDelta 是一个图谱化非线性讨论系统。它把普通评论区中的连续发言转化为节点和关系，让用户能够看到观点如何被提出、延续、分叉、合并、总结和治理。

## 2. 要解决的问题

传统论坛、群聊和评论区通常按时间排序。讨论一旦变长，会出现几个问题：

- 新用户很难快速理解讨论来龙去脉。
- 相似观点、反驳观点和补充证据混在一起，不容易归纳。
- 阶段性结论缺少清晰来源。
- 管理者难以追踪某个结论由哪些原始发言演化而来。

RhizoDelta 的核心想法是把讨论表达为图谱：节点代表用户发言、AI 共识、结果和摘要，边代表继承、分叉、合并、关联等关系。

## 3. 项目定位

本课程设计关注前端实现。正式报告中的源码依据是：

- 前端源码目录：`/home/tthm/workspace/RhizoDelta/frontend`
- 入口路由：`src/App.tsx`
- 工作区组件：`src/components/GraphWorkspace.tsx`
- 桌面工作区：`src/components/DesktopGraphWorkspace.tsx`
- 移动端讨论树：`src/components/mobile/MobileDiscussionTreeView.tsx`
- API 封装：`src/api/client.ts`
- SSE 事件处理：`src/hooks/useSse.ts`
- 状态管理：`src/stores/*.ts`

课程名称虽然是《Vue.js应用开发》，但本项目真实落地采用 React 技术栈。答辩时可以解释为：课程训练目标是前端应用开发能力，报告以真实工程为准，重点展示组件化、路由、状态管理、接口封装、响应式和工程化能力。

## 4. 用户角色与使用路径

普通用户的主要路径：

1. 登录或注册。
2. 在首页浏览根话题和动态。
3. 进入某个话题工作区。
4. 在桌面端查看图谱关系，或在移动端查看讨论树。
5. 选择节点查看详情、溯源、关联和审计信息。
6. 发布新话题或回复现有节点。
7. 等待后端异步处理，前端通过 SSE 自动刷新节点、边和状态。

具备治理权限的用户还可以执行延续注入、分叉、复核等操作。

## 5. 核心功能模块

| 模块 | 作用 | 代表源码 |
|---|---|---|
| 登录与路由鉴权 | 区分公开页面和受保护页面 | `src/App.tsx`, `src/stores/authStore.ts` |
| 首页入口 | 展示根话题、动态和快捷入口 | `src/components/home/*` |
| 图谱工作区 | 展示节点、边、话题列表和详情面板 | `src/components/DesktopGraphWorkspace.tsx` |
| 移动端讨论树 | 在小屏设备上用嵌套评论结构代替复杂图谱 | `src/components/mobile/MobileDiscussionTreeView.tsx` |
| 发布与回复 | 提交用户输入并等待异步编排 | `src/components/forms/PostForm.tsx` |
| 节点详情与治理 | 展示正文、溯源、关联、审计和操作入口 | `src/components/panels/*` |
| 实时更新 | 通过 SSE 接收节点、边、决策和质量评分事件 | `src/hooks/useSse.ts` |
| 检索命令面板 | 支持快速定位节点和相似内容 | `src/components/search/CommandPalette.tsx` |

## 6. 项目亮点

1. 信息结构有创新：不是普通列表式评论，而是图谱化讨论。
2. 前端模块完整：包含认证、首页、工作区、详情面板、移动端适配、设置页和实时更新。
3. 数据流清晰：组件负责交互，API 层负责请求，Zustand store 负责跨组件状态。
4. 桌面和移动端分别设计：桌面强调图谱探索，移动端强调阅读和回复效率。
5. 实时性较强：通过 SSE 接收后端事件，减少用户手动刷新。
6. 可维护性较好：业务 API、store、组件和工具函数按职责拆分，源码中有多处测试文件。

## 7. 答辩时的重点表达

可以按“为什么做、做了什么、怎么设计、难点如何解决、学到了什么”展开：

- 为什么做：长讨论难以理解，需要图谱化组织观点。
- 做了什么：实现登录、首页、图谱工作区、移动端讨论树、发布回复、节点详情、实时更新和设置页。
- 怎么设计：React 路由负责页面组织，Zustand 管理状态，统一 API 客户端处理请求，SSE 实现实时刷新。
- 难点如何解决：桌面和移动端分开呈现，复杂图谱数据通过 store 统一管理，异步结果通过事件驱动更新。
- 学到了什么：理解了完整前端项目中的组件化、数据流、接口封装、响应式和工程化实践。
